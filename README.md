# Research Projects

This repository serves as an index and documentation hub for the works listed below. Each project is maintained in its respective repository, with links to the source code and associated publications where available.

## Projects

### 1. PIGNN — Physics-Informed Graph Neural Network

A generalizable physics-informed graph neural network for predicting CO2 solubility across different amine classes.

**Repository:** [amine-co2-pignn](https://github.com/afriwahyudi/amine-co2-pignn)

**Publication:** Wahyudi, A., Sueviriyapan, N., & Suriyapraphadilok, U. (2025). Generalizable physics-informed graph neural network for CO2 solubility prediction across amine classes. *Separation and Purification Technology*, 136395.

---

### 2. DeepThermoMix

A local composition graph neural network model for predicting multicomponent activity coefficients.

**Repository:** [deepthermomix](https://github.com/afriwahyudi/deepthermomix)

**Publication:** Wahyudi, A., Sueviriyapan, N., Rirksomboon, T., & Suriyapraphadilok, U. (2026). DeepThermoMix: A local composition graph neural networks model for multicomponent activity coefficients. *ChemRxiv*.

---

### 3. DeepThermoMix-T

A temperature-dependent extension of DeepThermoMix for predicting thermodynamic behavior across varying temperatures.

**Repository:** [deepthermomix-t](https://github.com/afriwahyudi/deepthermomix-t)

**Publication:** Wahyudi, A. (2026). Rethinking Local Composition Theory: A Principled Graph-Based Approach in Mixture Thermodynamics. Doctoral dissertation, Chulalongkorn University. Chapter 6.

---

### 4. Geometric Visualization of the Multicomponent Gibbs–Duhem Equation

A geometric visualization and computational representation of the multicomponent Gibbs–Duhem equation in a PyTorch-compatible formulation.

**Repository:** [geometric-gibbs-duhem](https://github.com/afriwahyudi/geometric-gibbs-duhem)

**Publication:** Wahyudi, A. (2026). Rethinking Local Composition Theory: A Principled Graph-Based Approach in Mixture Thermodynamics. Doctoral dissertation, Chulalongkorn University. Chapter 7.

---

### 5. MSI-GNN — Mixture-Size-Invariant Graph Neural Network

A cross-mixture-size graph neural network for predicting CO₂ solubility in multicomponent amine solvents.

**Repository:** [amine-blend-model](https://github.com/afriwahyudi/amine-blend-model)

**Publication:** Wahyudi, A., Sueviriyapan, N., & Suriyapraphadilok, U. (2026). Cross-mixture-size graph neural network for CO2 solubility prediction in multicomponent amine solvents. *ChemRxiv*.

---

## Repository Structure

This repository intentionally contains no source code from the projects listed above. It serves as a centralized index and documentation hub, providing a common entry point to the associated source repositories, publications, and other research resources.

The individual projects remain independently version-controlled and retain their respective repositories, histories, and licenses.
